# Entre Flores y Código

Videojuego educativo 2D hecho en **Godot 4.7** (GDScript). Aby (o Josmar) estudia Desarrollo de Software en la UTHH y trabaja en la Florería Bautista: aprueba los cuatrimestres de la carrera de TI, arma ramos y presenta su proyecto final.

- **Documentación técnica e historia:** [`docs/`](docs/)
- **Ejecutable para Windows:** ver la sección *Releases* del repositorio (descargar el .zip, descomprimir y abrir `EntreFloresYCodigo.exe`).
- **Abrir el código:** instalar Godot 4.7 → Importar → `project.godot`.

Controles: WASD o flechas para moverse, clic para interactuar, Esc para pausa.

Autora: Alondra Abigail Torres Badillo — UTHH, 10° B.
